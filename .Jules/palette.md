## 2026-10-28 - Contextual Button Action Feedback
**Learning:** Providing temporary inline feedback directly on action buttons (e.g. changing "Copy" to "Copied!") gives immediate and reassuring feedback at the focal point of user interaction, avoiding reliance on distant status fields that may use error formatting.
**Action:** Always provide brief inline text/visual state changes on copy and action buttons upon user interaction, and pair ARIA labels with `title` attributes for tooltips on icon buttons.
